# Redefine Meat

> Redefine Meat is an Israeli food-technology company, founded in 2018, that manufactures plant-based whole-cut meat alternatives it markets as New-Meat, using industrial 3D printing and plant-protein formulations it calls Alt-Muscle, Alt-Fat and Alt-Blood. It sells consumer (B2C) and foodservice (B2B / PRO) ranges through restaurants, hotels, caterers and retail in the UK, Germany, the Netherlands, France and Israel.

Provenance: this file was GENERATED by API Evangelist on 2026-08-05 from the company's public
website and its live API surface. Redefine Meat does not publish an llms.txt of its own —
`https://www.redefinemeat.com/llms.txt` returns HTTP 200 with the site's theme homepage, byte
identical to a control path, i.e. a soft-404. An llms.txt generator plugin is installed on the
site (the `llms/v1` REST namespace is registered) but no file is served.

Redefine Meat operates no developer program, no developer portal and no API documentation.
Nevertheless its WordPress + WooCommerce website exposes a real, publicly readable API surface.

## APIs

- [Store API](https://www.redefinemeat.com/wp-json/wc/store/v1): WooCommerce Store API — product catalog, categories, attributes, brands, tags, reviews, cart and checkout. Reads are anonymous; writes require a `Nonce` header and a `Cart-Token` session.
- [Content API](https://www.redefinemeat.com/wp-json/wp/v2): WordPress REST API — posts, pages, media, comments, taxonomies and the site's custom post types (product, pr, news, recipe, event). Collection reads are anonymous.
- [MCP server](https://www.redefinemeat.com/wp-json/mcp/mcp-oauth-server): Model Context Protocol endpoint, OAuth 2.1 gated (scope `mcp`). An anonymous `tools/list` returns HTTP 401, so the tool set is unknown.

## Conventions

- Pagination: `page` + `per_page` (max 100); `X-WP-Total`, `X-WP-TotalPages` and RFC 8288 `Link` response headers.
- Errors: WordPress envelope `{code, message, data.status}` — not RFC 9457 problem+json.
- Idempotency: not supported. No idempotency key on any of the 845 routes.
- Rate limits: no RateLimit or Retry-After headers observed, and no published policy.
- Versioning: namespace path segment. `wc/v1`, `wc/v2` and `wc/v3` are served concurrently with no deprecation signalling.
- Schema discovery: an HTTP `OPTIONS` request on any route returns that route's own JSON Schema.

## Caution for agents

- The site answers HTTP 200 with its full theme homepage for **any** unmatched path. A 200 is not evidence a document exists — diff the body against a control path before trusting it.
- There is no status page, no changelog, no SLA, no deprecation policy, no security.txt and no trust center. Nothing on this host is a supported public API and none of it carries a stability promise.
